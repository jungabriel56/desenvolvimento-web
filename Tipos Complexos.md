Utilizados para passar coleções de dados ou objetos completos, permitindo que componentes recebam informações estruturadas.

- **Exemplos:** `array` (listas), `object` (objetos literais), `shape` (objetos com estrutura específica). 
    
- **Uso:** Listas de itens, configurações de estilo, dados de usuário completos. 
    
- **Validação:** `PropTypes.array`, `PropTypes.object`, `PropTypes.shape({ ... })`.
