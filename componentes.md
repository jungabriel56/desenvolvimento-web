Os componentes são como blocos de código reutilizáveis, assim como funções do JavaScript. Para diferenciar um componente de uma função, é necessário que o nome incie com letra maiúscula.

### Principais características
- ***Reutilização***: Existe a possibilidade de reutilizar componentes em diversas partes do código;
- ***Composição***: Componentes pequenos podem ser combinados para criar interfaces maiores;
- ***Estrutura***: São funções JavaScript que retornam [[JSX]]
